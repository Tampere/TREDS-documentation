# AppHeader

<ComponentBadges name="AppHeader" lang="en" />

The app header is the bar at the top of the site: the Tampere logo, the service name, the main menu, the language switcher and login. On narrow screens the menu and the languages move behind a Menu button.

<ComponentLinks name="AppHeader" lang="en" />

<Example name="app-header/Hero" lang="en" scroll />

The header of this site is also an AppHeader. The header adapts to the browser window's width, not to the example box, so in the examples its row can wrap onto two lines. Resize the browser window to see how this page's header adapts.

## When to use

Use the app header on every page of every City of Tampere web service, always the same way. It is the page's `<header>`, followed by the main content.

**Don't use an app header when**

- you need in-page navigation, like a section's subpages – use a sidebar or <ComponentRef name="NavigationLink" lang="en" /> components in the content
- you need a breadcrumb trail – use <ComponentRef name="Breadcrumbs" lang="en" /> below the header

## Variants and situations

### Single-row header

In the default layout everything is on one row, as in the example at the top of the page. Parts move behind the Menu button as the screen narrows:

<HeaderCollapseTable lang="en" />

The service name (`siteName`) is hidden on screens under 768 pixels. Without `navigation` there is no Menu button, and the languages and actions stay on the row at every width.

### Multi-row header and search

`layout="multi-row"` adds a second row with a search field (`search`) and the main menu. The first row can also hold a secondary navigation (`secondaryNavigation`), which moves into the menu on screens under 1024 pixels. Use <ComponentRef name="SearchField" lang="en" /> without a visible label for the search.

<Example name="app-header/MultiRow" lang="en" scroll />

The single-row layout has no search slot. Put a button that leads to search in the actions instead.

### Actions and login

`actions` adds actions with icons, like help. They move into the menu on screens under 768 pixels. `login` is always visible. Once the user has logged in, show the user's name and the `UserIcon` icon in the same place.

<Example name="app-header/Actions" lang="en" scroll />

### Router links

When the app uses its own router, like Next.js's `Link` component, give the menu items `renderLink` instead of `href`. `renderLink` receives a class and an `aria-current` value, which you must pass to the link. `isSelected` marks the current section.

<Example name="app-header/RouterLinks" lang="en" scroll />

## Content guidelines

- Keep the service name short: "e-Services", "Libraries".
- Keep the main menu short, with few items: all of them must fit on one row on a 1440-pixel screen.
- In Figma the languages are uppercase language codes: "FI", "SV", "EN". Each language's `code` and `currentLanguage` are lowercase, like `fi`.
- **The built-in texts are Finnish:** the Menu button ("Valikko"), the language switcher's name ("Kieli") and the secondary navigation's name. On an English page, pass `menuButtonLabel`, `languagesAriaLabel` and `secondaryNavAriaLabel`.

## Accessibility

**The component handles**

- The header is a `<header>` landmark. The main menu, the language switcher and the secondary navigation are named `<nav>` landmarks.
- The logo is a link to the home page, named "Tampere".
- The selected menu item gets `aria-current="page"` and the selected language `aria-current="true"`.
- The Menu button tells with `aria-expanded` whether the menu is open. Tab moves from the button to the first link in the menu, and Esc closes the menu and returns focus to the button. The menu also closes on a click outside it or when a link is chosen.
- Each link is in the accessibility tree only once: on the row or in the menu.

**Your responsibility**

- Name the main menu with `navAriaLabel`, for example "Main menu".
- Add a <ComponentRef name="SkipLink" lang="en" /> at the start of the page so keyboard users can skip the header.
- Screen readers read a language code like "FI" as it is, without saying which language it is. A language link can't yet be given the full language name as its accessible name, and it has no `lang` attribute (#230).

WCAG criteria: [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships.html), [2.4.1 Bypass Blocks](https://www.w3.org/WAI/WCAG21/Understanding/bypass-blocks.html), [2.4.3 Focus Order](https://www.w3.org/WAI/WCAG21/Understanding/focus-order.html), [3.1.2 Language of Parts](https://www.w3.org/WAI/WCAG21/Understanding/language-of-parts.html), [3.2.3 Consistent Navigation](https://www.w3.org/WAI/WCAG21/Understanding/consistent-navigation.html)
