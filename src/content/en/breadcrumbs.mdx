# Breadcrumbs

<ComponentBadges name="Breadcrumbs" lang="en" />

A breadcrumb shows where in the service's page hierarchy the user is, and leads to the levels above.

<ComponentLinks name="Breadcrumbs" lang="en" />

<Example name="breadcrumbs/Hero" lang="en" />

## When to use

Use a breadcrumb in services whose pages are at least two levels deep. Place it at the top of the page, below the header and before the page's main heading. This site's breadcrumb is an example.

**Don't use a breadcrumb when**

- the service has only one level, for example a home page and its subpages
- the user moves through a step-by-step form. A breadcrumb shows location, not steps.
- you want to link to pages on the same level – use <ComponentRef name="NavigationLink" lang="en" />

## Variants and situations

### Trail

Give `items` in order from the top level to the current page, as in the example at the top of the page. Leave `href` out of the current page: it shows as bold text, not a link.

A breadcrumb shows at most the last five levels. The first levels, the home page included, are dropped without any marker.

### Mobile view

`isMobile` shows only a link to the previous level, with an arrow. The component doesn't detect the screen width, so you decide the mode.

<Example name="breadcrumbs/Mobile" lang="en" />

### Router links

`linkComponent` renders the link with your own component, for example Next.js's `Link`. Pass the props the function receives to the link: they carry the class and the text.

<Example name="breadcrumbs/RouterLink" lang="en" />

## Content guidelines

- Use the pages' headings, or short forms of them, as the level names.
- Keep the names short.
- Set `ariaLabel` to "Breadcrumb" ("Murupolku" in Finnish).

## Accessibility

**The component handles**

- The breadcrumb is a `<nav>` region with the levels in an ordered list `<ol>`. Screen readers announce the number of levels.
- The upper levels are native links.

**Your responsibility**

- Always give `ariaLabel`, so the breadcrumb can be told apart from the page's other navigations.
- Leave `href` out of the current page.
- Check that the trail fits the narrowest view, or use `isMobile` there.

WCAG criteria: [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships.html), [1.4.10 Reflow](https://www.w3.org/WAI/WCAG21/Understanding/reflow.html), [2.4.7 Focus Visible](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible.html), [2.4.8 Location](https://www.w3.org/WAI/WCAG21/Understanding/location.html), [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html)
