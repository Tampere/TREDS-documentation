# Checkbox

A checkbox lets the user select one or more options, or confirm a single thing.

## When to use

Use checkboxes when the user can select any number of options, including none. A single checkbox suits a yes/no choice that is saved with the form.

**Don't use a checkbox when**

- the user may select only one option – use <ComponentRef name="RadioButton" lang="en" />
- the setting takes effect immediately, without submitting a form – use <ComponentRef name="Switch" lang="en" />
- the user filters content on the page – use <ComponentRef name="Chip" lang="en" />

## Variants and situations

### Groups and a single checkbox

Group related checkboxes with <ComponentRef name="Fieldset" lang="en" />, as in the example at the top of the page. `legend` states the question, and the `fieldsetSelectionGroup` class stacks the checkboxes with the right spacing. A single checkbox doesn't need a group. Its label alone says what the choice means.

<Example name="checkbox/Single" lang="en" />

### Select all

`indeterminate` shows the checkbox as partly selected. Use it on a "select all" checkbox when only some of the options below it are selected. The component doesn't work out the state itself: derive `checked` and `indeterminate` from the options below.

## Accessibility

- Write the label in the positive: "Send a confirmation to my email", not "Don't send a confirmation". Avoid links in the label. Give terms or further information above the checkbox.
- Phrase the group's `legend` as a question that the options answer, and order the options logically, for example alphabetically or from most to least common.
- Group related checkboxes with Fieldset, so the group has a name screen readers announce.
- `error` only colours the checkbox. Give the group an error message with Fieldset's `error` prop and set `aria-invalid` on the checkboxes.
- When a form is submitted with errors, move focus to the first invalid field or to an error summary.
- If at least one option in a group must be selected, check it yourself: native `required` requires each checkbox separately. Mark the group with Fieldset's `showRequiredMarker` prop and state the requirement with `helperText`.
- A disabled checkbox can't be focused with the keyboard, so explain elsewhere why the choice isn't available.
- Derive a "select all" checkbox's `checked` and `indeterminate` from the options below, so the state screen readers announce is correct.
