# Chip

<ComponentBadges name="Chip" lang="en" />

A chip is an interactive label: the user can select it as a filter or remove it.

<ComponentLinks name="Chip" lang="en" />

<Example name="chip/Hero" lang="en" />

## When to use

Use a chip when the user filters or narrows content by selecting one or more options, or when you show the choices they have made as removable tags.

**Don't use a chip when**

- the label only states a status or category – use <ComponentRef name="Badge" lang="en" />
- pressing it triggers an action – use <ComponentRef name="Button" lang="en" />

## Variants and situations

### Filter chip

`checked` and `onChange` make the chip a filter chip, which works like a checkbox. A selected chip shows a checkmark. Several chips can be selected at once.

<Example name="chip/Filter" lang="en" />

### Filter chip with an icon

`icon` shows at the start of the chip while it isn't selected. When selected, a checkmark takes its place, which you can replace with `selectedIcon`.

<Example name="chip/WithIcon" lang="en" />

### Removable tag

`onRemove` and `removeLabel` make the chip a removable tag with a remove button. Use it, for example, to show the choices or search criteria the user has made.

<Example name="chip/Removable" lang="en" />

## Accessibility

- Keep the text short, one or two words. Order filter chips logically, for example alphabetically or by how often they are used.
- Group related filter chips with <ComponentRef name="Fieldset" lang="en" /> so the group has a name screen readers announce, such as "Show on map".
- Name the remove button after the tag: "Remove Hervanta", not a bare "Remove". Each `removeLabel` is unique, so the remove buttons can be told apart.
- When a tag is removed, move focus somewhere sensible, such as the next tag or the search field. Otherwise focus is lost with the removed button.
- If a selection changes the results on the page, announce the change to screen readers, for example the number of results in a live region.
