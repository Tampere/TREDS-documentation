# Colours

Pick colours by **role**, not by shade. Each colour below is a semantic token that says what it is for (body text, a link, an error), so a change to the palette reaches every service without anyone searching for hex codes.

Every value, swatch and contrast ratio on this page is read from the published `@tampere/treds` package when the site is built.

## Contrast

WCAG 2.1 level AA requires **4.5:1** for normal text and **3:1** for large text (24 px, or 18.66 px bold) and for the parts of a control you need to see to use it. Check text against the background it actually sits on:
