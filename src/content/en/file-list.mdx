# FileList

<ComponentBadges name="FileList" lang="en" />

A file list shows files as rows, and each row can be removed. The list doesn't hold the files itself: it gets them as props.

<ComponentLinks name="FileList" lang="en" />

<Example name="file-list/Hero" lang="en" />

## When to use

<ComponentRef name="FileInput" lang="en" /> and
<ComponentRef name="Dropzone" lang="en" /> show a file list themselves, so you don't need it
separately with them. Use the file list on its own when you show files the user attached earlier,
for example the attachments of a saved application, and the user can remove them.

**Don't use a file list when**

- the user chooses new files – use <ComponentRef name="Dropzone" lang="en" /> or <ComponentRef name="FileInput" lang="en" />
- files can't be removed – list them as links or text, because every row of a file list has a remove button

## Variants and situations

### Removing files

`onRemove` receives the index of the file to remove. Remove the file from your own state, and the list updates. When a row is removed, focus moves to the next row's remove button or, if the removed row was the last, to the previous one.

When the very last file is removed, the list disappears and has nothing left to focus. Pass `onEmptied` and move focus somewhere sensible in it, as the example at the top of the page does with the "Restore files" button. Otherwise focus drops to the start of the page.

### Disabled

`disabled` disables the remove buttons. The file names stay visible.

<Example name="file-list/Disabled" lang="en" />

## Content guidelines

- The file name is shown as is. A long name wraps and is not shortened.
- The remove button's name is `"Poista tiedosto: <file name>"` by default. On an English page, pass `removeLabel`.

## Accessibility

**The component handles**

- The files are in a `<ul>` list, so screen readers announce how many there are.
- Each remove button's name includes the file name, for example "Remove file: site-plan.pdf".
- After a removal, focus moves to the next or previous remove button.

**Your responsibility**

- Pass `onEmptied` and move focus in it when the list empties.
- Say what the files are next to the list, for example with a heading "Saved attachments". The list has no heading of its own.
- If removal can't be undone, ask for confirmation before you remove the file from your state.

WCAG criteria: [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships.html), [2.4.3 Focus Order](https://www.w3.org/WAI/WCAG21/Understanding/focus-order.html), [2.4.6 Headings and Labels](https://www.w3.org/WAI/WCAG21/Understanding/headings-and-labels.html)
