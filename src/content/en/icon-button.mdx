# IconButton

<ComponentBadges name="IconButton" lang="en" />

An icon button is a button with an icon only.

<ComponentLinks name="IconButton" lang="en" />

<Example name="icon-button/Hero" lang="en" />

## When to use

Use an icon button for a recurring action whose icon is unambiguous and where there's no room for text, for example in a table row's actions or as a close button.

**Don't use an icon button when**

- the action isn't clear from the icon – use <ComponentRef name="LabeledIconButton" lang="en" /> or <ComponentRef name="Button" lang="en" />
- it is the view's main action – use <ComponentRef name="Button" lang="en" />
- it takes the user to another page from within text – use <ComponentRef name="TextLink" lang="en" />

## Variants and situations

### Sizes

`size` sets the icon size: `xs` 16px, `sm` 18px, `md` 20px, `lg` 24px and `xl` 28px. The touch target is always at least 24 × 24px.

<Example name="icon-button/Sizes" lang="en" />

### On a dark background

`variant="inverted"` makes the icon and the focus ring light. Use it only on a dark or coloured background.

<Example name="icon-button/Inverted" lang="en" />

### As a link

`component="a"` and `href` make the icon button a link, for example to social media channels. Put link buttons in a flex row.

<Example name="icon-button/AsLink" lang="en" />

### Disabled

`disabled` prevents pressing and greys out the icon. A disabled button can't be focused with the keyboard, so explain elsewhere why the action isn't available.

<Example name="icon-button/Disabled" lang="en" />

## Content guidelines

- Write the `aria-label` as the action: "Edit", "Delete", "Close".
- Make the name unique when there are several similar buttons: "Delete attachment application.pdf", not just "Delete".
- Use the same icon for the same action across the service.

## Accessibility

**The component handles**

- The icon button is a native `<button type="button">`, so it doesn't submit a form by accident.
- The touch target is at least 24 × 24px (WCAG 2.5.8).
- A focused button gets the TREDS focus ring and background. In the `inverted` variant the ring is light.
- `disabled` is native, so screen readers announce the button as unavailable.

**Your responsibility**

- Always give `aria-label`. It is the button's only name: without it, screen readers hear just "button".
- Not everyone recognises an icon. If the action is rare or important, show text with <ComponentRef name="LabeledIconButton" lang="en" />.
- For an icon button used as a link, the `aria-label` names the destination, not an action: "City of Tampere on Facebook".

WCAG criteria: [1.1.1 Non-text Content](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content.html), [2.4.7 Focus Visible](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible.html), [2.5.8 Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html), [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html)
