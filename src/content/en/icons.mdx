# Icons

TREDS includes the City of Tampere icon set as React components. Each icon is drawn on a 24 px grid and takes its colour from the surrounding text, so it follows link, button and state colours without extra styling.

Need an icon for a presentation or a document? Pick it from the [list of all icons](#all-icons) and download it as a PNG or SVG image.

## Using an icon

```tsx
import { SearchIcon } from '@tampere/treds';

<SearchIcon aria-hidden="true" />; // 24px, current text colour
<SearchIcon aria-hidden="true" width={20} />; // other sizes: set width
```

Icons accept any SVG attribute. To change the colour, set `color` on the icon or a parent.

## Accessibility

Most icons sit next to text that already says what they mean. Those are **decorative**: hide them from assistive technology with `aria-hidden="true"` so screen readers don't announce an unnamed image.

When an icon is the **only** content of a control, the control needs an accessible name. <ComponentRef name="Button" lang="en" /> requires one at compile time:

```tsx
<Button iconOnly aria-label="Hae">
  <SearchIcon aria-hidden="true" />
</Button>
```

There is also a dedicated <ComponentRef name="IconButton" lang="en" /> for icon-only buttons, and <ComponentRef name="LabeledIconButton" lang="en" /> for an icon with a label.

Don't rely on an icon alone to convey meaning outside controls: pair it with text.

WCAG criteria: [1.1.1 Non-text Content](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content.html), [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html)
