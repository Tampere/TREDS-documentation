# Tampere Design System

TREDS is the component library behind the City of Tampere's digital services. It gives teams a set of accessible, visually consistent building blocks so that every Tampere service looks and behaves like part of the same city, and no team has to re-solve focus outlines, colour contrast and responsive type from scratch.

It is a React library, published as `@tampere/treds`, built on top of [Mantine](https://mantine.dev/). Mantine handles the unglamorous primitives, like popovers, focus traps and form state, and TREDS supplies Tampere's design decisions on top.

## Installing

The package is published to GitHub Packages rather than the public npm registry, so npm needs a registry setting and a token first. The [setup steps](https://github.com/Tampere/Tampere-design-system#setup-with-npm-package) are in the TREDS README.

```bash
npm install @tampere/treds
```

Wrap your app once, at the root:

```jsx
import { ThemeProvider } from '@tampere/treds';

<ThemeProvider>
  <App />
</ThemeProvider>;
```

## Versioning

TREDS follows semantic versioning from 1.0.0: breaking changes bump the major version. Every release's breaking and visual changes are listed under "Upgrade notes" in the [changelog](https://github.com/Tampere/Tampere-design-system/blob/main/CHANGELOG.md).
