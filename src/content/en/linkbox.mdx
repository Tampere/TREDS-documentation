# Linkbox

<ComponentBadges name="Linkbox" lang="en" />

A linkbox is a box-shaped link: the whole box leads to one destination.

<ComponentLinks name="Linkbox" lang="en" />

<Example name="linkbox/Hero" lang="en" />

## When to use

Use a linkbox to highlight content or a section of the service that the user moves to, for example service highlights on a home page. A linkbox has a title, and it can have a short description and an image. Linkboxes usually go in a grid, as in the example at the top of the page. A linkbox doesn't lay itself out, so use a CSS grid and TREDS spacing.

**Don't use a linkbox when**

- the box contains several links or buttons – use <ComponentRef name="Card" lang="en" />
- the link is in the middle of text – use <ComponentRef name="TextLink" lang="en" />
- the links are in a navigation list – use <ComponentRef name="NavigationLink" lang="en" />
- pressing it does something on the page – use <ComponentRef name="Button" lang="en" />

## Variants and situations

### Image

`media` shows an image at the top of the box in a 3:2 frame. `mediaPlacement="left"` puts the image on the left, and when the box is narrower than 768px, the image moves back to the top.

<Example name="linkbox/Media" lang="en" />

### Inverted

`inverted` makes the box turquoise and the text white. It stands out best on a white page. On a white page the edge of a regular box doesn't show, so a regular box works best on a coloured or grey background.

<Example name="linkbox/Inverted" lang="en" />

### External link

`external` swaps the arrow for the external link icon, opens the link in a new tab and adds the text "(avautuu uuteen välilehteen)" to the link's name. In other languages, give the text with `externalLabel`. Use external links sparingly: a new tab breaks returning with the Back button.

<Example name="linkbox/External" lang="en" />

## Accessibility

- Write the title as the name of the target page. The title is the link's name: screen readers don't read the `eyebrow` and `description` as part of it.
- Make titles unique. Two boxes with the same name leading to different places confuse users browsing a list of links.
- Choose the heading level to fit the page structure with `titleOrder`.
- Keep the description to one sentence and say what the target offers. Use the `eyebrow` text for classification, for example "Services" or "News".
