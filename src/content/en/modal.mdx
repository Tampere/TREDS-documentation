# Modal

<ComponentBadges name="Modal" lang="en" />

Modal is a dialog that opens on top of the page. The rest of the page is unavailable while it is open.

<ComponentLinks name="Modal" lang="en" />

<Example name="modal/Hero" lang="en" />

## When to use

Use Modal when the user must answer or do a short task before they can continue, for example confirming an irreversible deletion.

**Don't use Modal when**

- the content is long or has several steps – make it a page of its own
- you only want to tell the user something – show a message on the page
- the user needs to see the page content at the same time
- you would open another modal on top of a modal

## Variants and situations

### Confirmation

The example at the top of the page asks to confirm a deletion. Name the buttons after the action, such as "Delete" and "Cancel", not "Yes" and "No". Modal doesn't lay out a button row for you; you place the buttons.

### Form

When it opens, Modal moves focus to the first focusable element, which is the close button. In a form, move focus to the first field with the `data-autofocus` attribute. Button doesn't accept `type="submit"` yet (#223), so the example saves in both the button's `onClick` and the form's `onSubmit` handler. The latter handles the Enter key.

<Example name="modal/Form" lang="en" />

### Size

`size` is `xs`, `sm`, `md` (default), `lg` or `xl`, or a width as a number or a percentage. On a narrow screen Modal shrinks to the screen width.

<Example name="modal/Size" lang="en" />

### Title

`title` is shown as an `h2` heading, and it is also the dialog's name. Always give Modal a title: without one the dialog has no name (#222).

## Content guidelines

- Write the title as a question or an action: "Delete the application?"
- Say what happens in the text: "A deleted application cannot be restored."
- Keep the content short. If it needs scrolling, consider a page of its own.

## Accessibility

**The component handles**

- Modal has the `dialog` role and `aria-modal`. The title is its name and the content its description.
- Focus moves into the dialog when it opens and returns to the opening button when it closes.
- The Tab key cycles only inside the dialog. Esc and a click on the backdrop close it.
- Page scrolling is locked while the dialog is open.
- The close button's name is required in `closeButtonProps`.

**Your responsibility**

- Always give a `title` (#222).
- Give the close button a name in the page language, for example "Close".
- `onClose` is the only way Modal closes. Update the `opened` state in it, or Esc, the backdrop click and the close button do nothing.
- Move focus to a form's first field with the `data-autofocus` attribute.

WCAG criteria: [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships.html), [2.1.2 No Keyboard Trap](https://www.w3.org/WAI/WCAG21/Understanding/no-keyboard-trap.html), [2.4.3 Focus Order](https://www.w3.org/WAI/WCAG21/Understanding/focus-order.html), [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html)
