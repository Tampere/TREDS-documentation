# Modal

<ComponentBadges name="Modal" lang="en" />

Modal is a dialog that opens on top of the page. The rest of the page is unavailable while it is open.

<ComponentLinks name="Modal" lang="en" />

<Example name="modal/Hero" lang="en" />

## When to use

Use Modal when the user must answer or do a short task before they can continue, for example confirming an irreversible deletion.

**Don't use Modal when**

- the content is long or has several steps – make it a page of its own
- you only want to tell the user something – show a message on the page
- the user needs to see the page content at the same time
- you would open another modal on top of a modal

## Variants and situations

### Form

When it opens, Modal moves focus to the first focusable element, which is the close button. In a form, move focus to the first field with the `data-autofocus` attribute.

<Example name="modal/Form" lang="en" />

## Accessibility

- Always give a `title`. It is the dialog's name, so write it as a question or an action: "Delete the application?"
- Say what happens in the text: "A deleted application cannot be restored." Keep the content short. If it needs scrolling, consider a page of its own.
- Name the buttons after the action, such as "Delete" and "Cancel", not "Yes" and "No".
- Give the close button a name in the page language through `closeButtonProps`, for example "Close".
- `onClose` is the only way Modal closes. Update the `opened` state in it, or Esc, the backdrop click and the close button do nothing.
- In a form, move focus to the first field with the `data-autofocus` attribute.
