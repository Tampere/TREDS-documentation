# NavigationLink

<ComponentBadges name="NavigationLink" lang="en" />

A navigation link takes the user to another page of the service from a navigation, and shows which page the user is on.

<ComponentLinks name="NavigationLink" lang="en" />

<Example name="navigation-link/Hero" lang="en" />

## When to use

Use navigation links in link lists that move the user between the service's pages: section navigation, the footer and your own navigation menus. <ComponentRef name="AppHeader" lang="en" /> and <ComponentRef name="Footer" lang="en" /> already use it.

**Don't use a navigation link when**

- the link is in the middle of body text – use <ComponentRef name="TextLink" lang="en" />
- the link highlights content that has a title and a description – use <ComponentRef name="Linkbox" lang="en" />
- pressing it does something on the current page – use <ComponentRef name="Button" lang="en" />
- you show the page's place in the hierarchy – use <ComponentRef name="Breadcrumbs" lang="en" />

## Variants and situations

### Link list

A navigation link is an inline element with no spacing of its own. Lay the links out yourself, for example with flex and a TREDS spacing token. Mark only one link per navigation as selected with `isSelected`. `size="sm"` is for secondary link lists, like the footer's legal links.

<Example name="navigation-link/Small" lang="en" />

### Icons

`startIcon` adds an icon before the text and `endIcon` after it. Give the icons `aria-hidden`, as in the example.

<Example name="navigation-link/WithIcons" lang="en" />

### On a dark background

`variant="inverted"` makes the text, the underline and the focus ring light. Use it only on a dark or coloured background.

<Example name="navigation-link/Inverted" lang="en" />

### Router link

`renderLink` replaces the default `<a>` element, for example with Next.js's `Link`. The function gets the class and the `aria-current` value, and you must apply them yourself. `href`, `startIcon` and `endIcon` don't work with `renderLink`: give the address and the icons to your own element.

<Example name="navigation-link/RouterLink" lang="en" />

## Accessibility

- Wrap navigation links in a `<nav>` element and give it an `aria-label` that tells it apart from the page's other navigations.
- Always give `href` or `renderLink`. Without them the link has no address: it can't be focused, and screen readers don't recognise it as a link.
- Write the link text as the name of the target page: "Housing advice", not "Read more". Use the same name in the link and in the target page's heading.
- With `renderLink`, set the `aria-current` the function receives on your own element. Otherwise the current page isn't announced.
