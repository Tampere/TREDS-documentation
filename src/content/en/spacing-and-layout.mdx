# Spacing and layout

## Spacing scale

Seven steps, from `xxs` to `xxl`. Like type, the scale is responsive: the same step is smaller on narrow screens. Components use it internally; use the same steps in your own layouts so spacing stays consistent with them.

## Spacing between text blocks

TREDS doesn't yet define spacing between headings and paragraphs — `Typography` sets no margins, so each service decides its own. This is tracked as a missing token in [#180](https://github.com/Tampere/Tampere-design-system/issues/180). Until it lands, this site uses the scale above: `sm` between paragraphs, `xl` before an `h2` and `xs` after a heading.

## Breakpoints

Six breakpoints. Note that a key's values apply **below** its own width — `lg` (1024px) covers viewports from 768px to 1024px. Tokens switch automatically with CSS media queries, so components need no JavaScript breakpoint logic.

The layout grid — columns, gutter and outer margin — changes at the same breakpoints.
