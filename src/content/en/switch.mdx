# Switch

<ComponentBadges name="Switch" lang="en" />

A switch turns a setting on or off. The change takes effect immediately.

<ComponentLinks name="Switch" lang="en" />

<Example name="switch/Hero" lang="en" />

## When to use

Use a switch for a setting that is either on or off and takes effect immediately, without a save or submit button. For example, a filter that narrows a list on the page.

**Don't use a switch when**

- the choice is saved only when a form is submitted – use <ComponentRef name="Checkbox" lang="en" />
- the options have names of their own, like "In Finnish" and "In English" – use <ComponentRef name="RadioButton" lang="en" />
- the user filters content with several parallel choices – use <ComponentRef name="Chip" lang="en" />

## Variants and situations

### Single switch

The label is to the left of the switch, as in the example at the top of the page. You always own the switch's state: give `checked` and update it in the `onChange` handler.

### Switch group

Group related switches with <ComponentRef name="Fieldset" lang="en" />. The `legend` says what the settings are about, and the `fieldsetSelectionGroup` class stacks the switches. A switch follows its label, so switches with labels of different lengths don't line up.

## Content guidelines

- Write the label as the name of the setting, not an action: "Show open places only", not "Click to filter".
- Don't change the label with the state. The switch shows the state itself.
- Write the label positively, so that "on" means what the label says.

## Accessibility

**The component handles**

- The switch is a native `<input type="checkbox">` with the role `switch`, and `label` is its `<label>`. Screen readers announce the name and the state "on" or "off".
- Space toggles the state, and clicking the label toggles it too.
- The state is also shown by an icon and the thumb's position, not by colour alone.

**Your responsibility**

- Always give `label`. If the visible label is elsewhere, give `ariaLabel`. Note the name: `ariaLabel`, not `aria-label`.
- If the switch changes content elsewhere on the page, tell screen reader users, for example with the number of results in a `role="status"` region.

WCAG criteria: [1.4.1 Use of Color](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color.html), [2.4.7 Focus Visible](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible.html), [3.3.2 Labels or Instructions](https://www.w3.org/WAI/WCAG21/Understanding/labels-or-instructions.html), [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html), [4.1.3 Status Messages](https://www.w3.org/WAI/WCAG21/Understanding/status-messages.html)
