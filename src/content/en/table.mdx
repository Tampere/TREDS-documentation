## When to use

Use a table when the items share the same attributes and the user compares them, for example opening hours or application statuses. Keep the number of columns low: if there is a lot of data, consider whether the user needs all of it.

**Don't use a table when**

- you only want to place content side by side – use CSS layout
- each item has only one piece of data – use a list
- the items differ in content and link onwards – use <ComponentRef name="Card" lang="en" /> or <ComponentRef name="Linkbox" lang="en" />

## Variants and situations

### Structure and title

Table is made of parts that match the HTML table elements: `Table`, `TableHeader` (`<thead>`), `TableBody` (`<tbody>`), `TableRow` (`<tr>`), `TableHeaderCell` (`<th>`) and `TableCell` (`<td>`). The `title` of `TableHeader` is shown above the table as a `<caption>` and is the table's name, as in the example at the top of the page. If a heading already sits above the table, name the table with `aria-label` on `Table`.

### Wide table

Table doesn't scroll itself. A wide table overflows the page, so wrap it in a scrollable element.

<Example name="table/Scroll" lang="en" />

### Pagination

A long table can be split into pages with <ComponentRef name="Pagination" lang="en" />. Put it after the table in a `TableFooter` with `variant="div"`. State the page number in the table's title, and move focus when the page changes, as the <ComponentRef name="Pagination" lang="en">Pagination page</ComponentRef> explains.

<Example name="table/WithPagination" lang="en" />

## Accessibility

- Name the table with `title` or `aria-label`.
- Give every header cell a `scope`: `col` for a column header and `row` for a row header.
- Wrap a wide table in a scrollable element with `tabIndex={0}`, `role="region"` and a name, so it can be scrolled with the keyboard.
- Keep column headers short and unambiguous.
- Don't leave cells empty. Write, for example, "Closed" or "No data".
- Every row changes its background under the mouse, even though it can't be clicked. Don't let that mislead users: for example, don't write "click a row".

## API

Table, `TableBody`, `TableHeaderCell` and `TableCell` have no props of their own. Each part passes its props to its HTML element, for example `aria-label` to the table, `scope` to a header cell and `colSpan` to a cell.
