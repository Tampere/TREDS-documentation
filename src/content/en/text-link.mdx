## When to use

Use a text link when activating it takes the user somewhere else: another page, another service, a file or another part of the same page. A link can sit inside body text or on its own line.

**Don't use a text link when**

- it triggers an action on this page – use <ComponentRef name="Button" lang="en" />
- it belongs to the site's main or side navigation – use <ComponentRef name="NavigationLink" lang="en" />
- a whole card or box must be clickable – use <ComponentRef name="Linkbox" lang="en" />
- you need a link that skips to the main content – use <ComponentRef name="SkipLink" lang="en" />

## Variants and situations

### Size

The link is P1 by default. When the surrounding text is another size, give the link the same size with the `size` prop so the link doesn't stand out by its size. `size` accepts the whole typography scale, so a heading-sized link can serve as the title of an item in a listing.

<Example name="text-link/InText" lang="en" />

### External link

`openExternal` opens the link in a new tab and adds the external link icon. Its hidden screen reader text is Finnish by default, so set `openExternalLabel` on pages in other languages. Only open a new tab when there is a reason, for example while the user is filling in a form.

<Example name="text-link/External" lang="en" />

### Router link

`renderLink` replaces the `<a>` element with your own element, such as the `Link` component of Next.js or React Router. The function receives TextLink's class name, which you pass to your element. `href`, `openExternal` and the other props are then not applied: add them to your own element, including the external link indication, `target` and `rel`.

<Example name="text-link/RouterLink" lang="en" />

## Accessibility

- Say in the link text where the link goes, even out of context: "City of Tampere website", not "here" or a bare "read more".
- Don't use a web address as the link text unless the address itself is what the user needs.
- When the link goes to a file, give its format and size, for example "Application form (PDF, 2 MB)".
- Don't give the same link text to links that go to different places.
- A link must have `href` or `renderLink`. Without them it can't be reached with the keyboard.
