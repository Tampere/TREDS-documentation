# TimeField

## When to use

Use a time field when you ask for a time of day, for example an arrival time or the start of a booking.

**Don't use a time field when**

- there are only a few options, for example morning and afternoon or three free slots – use <ComponentRef name="RadioButton" lang="en" /> or <ComponentRef name="Select" lang="en" />
- you ask for a duration, like "how many hours" – use <ComponentRef name="TextField" lang="en" />

## Variants and situations

### The browser's time input

TimeField is the browser's own time input (`<input type="time">`) with TREDS styles. The field has separate segments for hours and minutes, and the clock button opens the browser's time picker, if the browser has one.

The display format comes from the user's browser language settings: a Finnish browser shows a 24-hour clock, an English one may show AM/PM. The value is still always `"HH:mm"`, for example `"09:30"`.

TimeField passes on the `name` prop, so its value travels in a normal form submission.

### Allowed range and step

`min` and `max` limit the allowed times, and `stepMinutes` the step in minutes. A time outside the range or off the step shows an error right away. State the limits and the step in the help text: "8 am–4 pm, in 15-minute steps".

When you ask for a point in time, use two fields side by side and group them with <ComponentRef name="Fieldset" lang="en" />.

## Accessibility

- Always give the field a visible `label`, named after the time you ask for: "Arrival time", not "Time". If a visible label isn't possible, give `aria-label` or `aria-labelledby`.
- Give the clock button a descriptive name with `pickerButtonLabel`, for example "Choose the arrival time".
- The built-in error messages and the clear button's name are Finnish. On an English page, pass `clearButtonLabel` and the three error props.
- The field checks three things itself: whether part of the time is missing (for example the minutes), whether the time is within the range and whether it fits the step. The messages can be changed with `invalidTimeError`, `outOfRangeError` and `stepMismatchError`.
- `error` shows your own error message and overrides the field's own messages. When there is no error, pass `undefined`, not an empty string: an empty string also overrides the field's own messages.
- The error message is not announced when it appears. When a form is submitted with errors, move focus to the first invalid field or to an error summary.
