# Typography

TREDS uses two typefaces: **Montserrat** for headings and **Open Sans** for everything else. `ThemeProvider` (see [Introduction](/en/)) loads both as variable fonts, so there is nothing to install separately.

The type styles cover headings, body text and small print. Use them through the <ComponentRef name="Typography" lang="en" /> component rather than setting font sizes yourself:

## Look and level are separate

`variant` sets how text **looks**, and `component` sets which HTML element it **is**. Keep the heading levels of a page in order for screen-reader users, and choose the look independently:

<Example name="typography/Level" lang="en" />

Use one `h1` per page, and don't skip levels: an `h4` directly under an `h2` breaks the outline that assistive technology users navigate by.

## Line length

Keep body text to roughly **80 characters per line** or fewer. WCAG 1.4.8 only requires this at level AAA, but it makes reading easier for everyone. Long lines are harder to follow back to the start of the next one, which matters most for readers with dyslexia or low vision. A content column of about 50rem does this at the p1 size.
