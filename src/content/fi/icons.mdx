# Ikonit

TREDS sisältää Tampereen kaupungin ikonisarjan React-komponentteina. Jokainen ikoni on piirretty 24 px:n ruudukkoon ja saa värinsä ympäröivästä tekstistä, joten se seuraa linkkien, painikkeiden ja tilojen värejä ilman erillistä tyylittelyä.

Tarvitsetko ikonin esitykseen tai dokumenttiin? Valitse se [kaikkien ikonien listasta](#kaikki-ikonit) ja lataa se PNG- tai SVG-kuvana.

## Ikonin käyttö

```tsx
import { SearchIcon } from '@tampere/treds';

<SearchIcon aria-hidden="true" />; // 24px, tekstin nykyinen väri
<SearchIcon aria-hidden="true" width={20} />; // muut koot: aseta width
```

Ikonit hyväksyvät kaikki SVG-attribuutit. Vaihda väriä asettamalla `color` ikonille tai sen vanhemmalle.

## Koot

Komponentit käyttävät näitä kokoja. Suosi niitä omissa asetteluissasi mielivaltaisten arvojen sijaan.

## Saavutettavuus

Useimmat ikonit ovat tekstin vieressä, joka jo kertoo niiden merkityksen. Ne ovat **koristeellisia**: piilota ne avustavalta teknologialta `aria-hidden="true"`-attribuutilla, jotta ruudunlukija ei ilmoita nimetöntä kuvaa.

Kun ikoni on kontrollin **ainoa** sisältö, kontrolli tarvitsee saavutettavan nimen. <ComponentRef name="Button" lang="fi">Button</ComponentRef> vaatii sen jo käännösvaiheessa:

```tsx
<Button iconOnly aria-label="Hae">
  <SearchIcon aria-hidden="true" />
</Button>
```

Pelkälle ikonipainikkeelle on myös oma <ComponentRef name="IconButton" lang="fi">IconButton-komponentti</ComponentRef>, ja kuvakkeelle tekstin kanssa <ComponentRef name="LabeledIconButton" lang="fi">LabeledIconButton</ComponentRef>.

Älä välitä merkitystä pelkällä ikonilla kontrollien ulkopuolella, vaan liitä mukaan teksti.

WCAG-kriteerit: [1.1.1 Ei-tekstuaalinen sisältö](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content.html), [4.1.2 Nimi, rooli, arvo](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html)

## Kaikki ikonit

Valitse ikoni, niin voit ladata sen kuvana tai kopioida sen JSX-koodin. PNG-kuva on 512 × 512 px ja läpinäkyvä, ja se sopii esimerkiksi PowerPointiin, Wordiin ja Teamsiin. SVG-kuva pysyy terävänä kaikissa koissa.
