# Design tokenit

Jokainen TREDSin väri, koko ja välistys tulee nimetystä tokenista. Komponenteissa ei ole kovakoodattuja hex-arvoja tai pikseliarvoja, eikä niitä pitäisi olla niiden päälle kirjoitetussa koodissakaan. Token on se tapa, jolla Figmassa kerran tehty päätös päätyy kaikkiin Tampereen palveluihin yhtä aikaa.

Tämä sivu on kehittäjille. Itse arvot ovat sivuilla [Värit](/fi/foundations/colours/), [Typografia](/fi/foundations/typography/) ja [Välistys ja asettelu](/fi/foundations/spacing-and-layout/).

## Neljä tasoa

Tokenit on kerrostettu, ja lähes aina oikea taso on **theme**.

- **Primitives** — raaka paletti ilman merkitystä: `primitives.colors.blue['400']`.
- **Brand** — Tampereen siniset roolin mukaan: `brand.blue.main`, `.mainLight`, `.mainDark`.
- **Theme** — mihin arvo on tarkoitettu: `vars.theme.text.primary`, `vars.theme.states.hover` sekä komponenttikohtaiset tokenit, kuten `vars.theme.components.button.fontWeight`.
- **Breakpoint** — taulukot breakpointeittain. Theme-taso valitsee oikean automaattisesti.

## Tokenien käyttö

`vars` sisältää viittauksia CSS-muuttujiin, joten se toimii kaikkialla, missä tyylin arvo on merkkijono — Vanilla Extract, inline-tyylit, CSS-in-JS:

```ts
import { vars } from '@tampere/treds';

const {
  theme: { text, states, strokeWeight, focusRing },
} = vars;

const field = {
  color: text.primary,
  border: `${strokeWeight} solid ${states.default}`,
};
```

Mediakyselyt vaihtavat muuttujien arvot, joten theme-token vastaa aina nykyisen näytön leveyden arvoa.

Tavallisista CSS-tiedostoista tokeneihin ei voi vielä viitata, koska muuttujien nimissä on build-hash. Asia on kirjattu issueksi [#180](https://github.com/Tampere/Tampere-design-system/issues/180).

## Miksi ei vain hex-arvoa?

Koska tokeneihin sisältyy päätöksiä, jotka eivät näy arvossa. `states.visited` on selvin esimerkki: Figman linkkiväri yltää valkoista vasten vain kontrastiin 3.24:1, mikä jää tekstiltä vaaditun WCAG AA -tason 4.5:1 alle, joten token käyttää tummempaa sinistä. Hex-arvon kopioiminen Figmasta tuottaisi saavutettavuusvirheen, jota ei huomaisi.

**Jos tarvitsemallesi arvolle ei ole tokenia, puute kannattaa ilmoittaa** sen sijaan, että arvo kirjoitettaisiin koodiin.
